Administration

Django Admin Panel

Auth & Account /api/auth/ (JWT)

POST /users/ Register a new user account
POST /jwt/create/ Obtain access & refresh tokens
POST /jwt/refresh/ Refresh access token
POST /jwt/verify/ Verify token validity
POST /logout/ Logout (invalidate token)
📘 Interactive docs: /auth/jwt/create/

Marketplace /api/marketplace/

GET /categories/ List all categories (public)
GET /categories/{slug}/ Retrieve a single category by slug
GET /ads/ List ads (filterable, public)
GET /ads/{id}/ Retrieve a single ad (public)
Nested GET / POST / PUT / DELETE /ads/{ad_pk}/images/
POST /guest/temporary-ads/ Create a temporary ad (guest)
GET /guest/temporary-ads/{id}/ Retrieve a temporary ad
Nested GET / POST / PUT / DELETE /guest/temporary-ads/{temporary_ad_pk}/images/

My Ads (Management) /api/marketplace/manage/ads/ (authenticated)

GET /manage/ads/ List your own ads
POST /manage/ads/ Create a new ad
GET /manage/ads/{id}/ Retrieve your ad
PUT / PATCH /manage/ads/{id}/ Update your ad
DELETE /manage/ads/{id}/ Delete your ad
🔒 Requires authentication. Only your own ads are visible.
🔍 filters Ads support filtering by status, is_featured, price, condition and search on product_name, description, category.
